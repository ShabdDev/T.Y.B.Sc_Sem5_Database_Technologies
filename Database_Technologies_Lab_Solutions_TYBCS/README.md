# CS-3010-MJ-P Database Technologies — Complete Set-Wise Lab Solutions

This folder contains solved practical work for the six assignments in the uploaded T.Y.B.Sc. Computer Science Database Technologies workbook.

The workbook identifies six assignments and states that Assignments 1–6 contain Sets A, B and C. Set A is described as mandatory, while Sets B and C provide additional practice. fileciteturn0file0L78-L90

## File naming

The requested naming pattern is used:

- `assignment1_SetA_1.md` = Assignment 1, Set A
- `assignment1_SetA_2.md` = Assignment 1, Set B
- `assignment1_SetA_3.md` = Assignment 1, Set C
- The same pattern is used through Assignment 6.

The final suffix `_1`, `_2`, `_3` therefore represents Set A, Set B, and Set C respectively.

## Important environment note

The workbook specifies Linux as the operating system and allows Linux editors such as `vi` and `gedit`; it also lists MongoDB and Neo4j as required software. fileciteturn0file0L117-L124

For MongoDB exercises, use `mongosh` with a current MongoDB installation. Some commands shown in the workbook use older `mongo` shell syntax; the solutions use current MongoDB shell syntax where appropriate.

For Neo4j exercises, run the Cypher blocks in Neo4j Browser.

## Execution advice

1. Install/start MongoDB before running MongoDB commands.
2. Run one database assignment in its own database to avoid name collisions.
3. Run Neo4j queries in Neo4j Browser.
4. Take screenshots of successful commands/results for the practical record.
5. Do not copy `ObjectId`, timing, or `explain()` statistics as fixed values; MongoDB generates IDs and execution statistics dynamically.
